## Next trial: observe WLAN takeover without changing hardware parameters

Trial 96 will keep the exact trial 93 effective DT, kernel, GSI/vendor and
test seeds. `display_bind.sh` adds a small read-only pinconf record before
and after each existing pins/fabric/core stage. It records GPIO20/21/79/80/81
to both the display log and kmsg. No GPIO requests, voltage votes, reset
writes, clock settings, rescan or firmware changes are added.

This distinguishes an inherited high WLAN_EN from a low-to-high enable
transition at fabric probe. The current PMU driver preserves the initial
WLAN enable value, while the board pinctrl lacks explicit output-low.
That is a testable hypothesis, not the diagnosed cause. PCIe power/PERST
ordering and trial 94's separate missing-ADB/reset failure remain open.
On a retained GSI boot, continue targeted inspection there; on failure,
restore the existing F.20 recovery set without another full stock reread.
